# GIST 604B Assignment 2: QGIS Desktop GIS Projects

## Overview

This repository documents ten QGIS tutorials completed for GIST 604B: Open Source GIS at the University of Arizona. The exercises demonstrate fundamental GIS workflows involving spatial data management, cartographic visualization, coordinate reference systems, attribute operations, and spatial analysis. Vector and raster datasets were used to explore geographic relationships, perform analytical operations, and develop maps using open source GIS software. The repository contains QGIS project files and screenshots documenting the completed tutorials.

## Software Environment

- **QGIS Version:** 3.44.15-Solothurn
- **Operating System:** Windows 11
- **Python Version:** 3.12.15
- **GDAL Version:** 3.13.3
- **PROJ Version:** 9.8.1
- **Active QGIS Plugins:** DB Manager, GRASS Provider, MetaSearch, Processing

- Examining and manipulating attribute tables
- Importing spreadsheets and CSV files into QGIS

## Reflection

Completing the QGIS tutorials provided practical experience with open source geospatial workflows and reinforced several concepts previously encountered in ArcGIS Pro. Working with coordinate reference systems, attribute tables, and spatial joins demonstrated how similar analytical operations are implemented across different GIS platforms. The Python programming tutorial was particularly useful because it introduced methods for accessing feature attributes and extracting geographic coordinates through the QGIS Python Console. One challenge involved understanding the differences between QGIS and ArcGIS Pro interfaces, particularly when locating processing tools and configuring project settings. Repeated practice with vector and raster datasets improved familiarity with QGIS data management and visualization capabilities. The exercises also demonstrated the flexibility of open source GIS software for performing spatial analysis without relying exclusively on proprietary applications. Knowledge gained through these tutorials can support future geospatial research involving environmental hazards, spatial data processing, and automated geographic analysis.
